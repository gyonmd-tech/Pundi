# Pundi Design System

Dokumentasi ini menjadi sumber aturan UI/UX Pundi selama proses redesign.

## Urutan baca

1. [`MASTER.md`](./MASTER.md) — fondasi brand, visual, komponen, responsive, motion, dan accessibility.
2. [`COMPONENT_ARCHITECTURE.md`](./COMPONENT_ARCHITECTURE.md) — aturan komponen dan arah modular produk.
3. `pages/<route>.md` — brief dan keputusan khusus halaman, jika tersedia.
4. [`DECISIONS.md`](./DECISIONS.md) — riwayat keputusan yang sudah diterima.

Gunakan [`PAGE_BRIEF_TEMPLATE.md`](./PAGE_BRIEF_TEMPLATE.md) ketika memulai redesign satu halaman.

## Prioritas aturan

1. Kebutuhan pengguna yang paling baru dan eksplisit.
2. Accessibility dan integritas data.
3. Brief halaman yang sudah disetujui.
4. Master design system.
5. Implementasi lama.

Implementasi lama bukan acuan visual jika bertentangan dengan dokumen ini.
